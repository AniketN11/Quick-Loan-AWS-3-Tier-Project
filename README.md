&#x20;🚀 Quick Loan - AWS 3-Tier Architecture Project



&#x20;📌 Project Overview

Quick Loan is a web application deployed using AWS cloud infrastructure. The project demonstrates a 3-tier architecture designed to improve scalability, availability, and security.



&#x20;🏗️ Architecture

The application uses separate network layers for public-facing services, application resources, and database resources.



&#x20;☁️ AWS Services and Technologies

\- 🖥️ \*\*Amazon EC2:\*\* Hosts application components.

\- 🌐 \*\*Amazon VPC:\*\* Provides network isolation.

\- ⚖️ \*\*Application Load Balancer (ALB):\*\* Distributes incoming application traffic.

\- 📈 \*\*Auto Scaling Group (ASG):\*\* Supports application instance scaling.

\- 🗄️ \*\*Amazon RDS (MySQL):\*\* Stores relational application data.

\- 📦 \*\*Amazon S3:\*\* Stores application assets.

\- 🔒 \*\*NAT Gateway:\*\* Enables outbound internet access from private subnets.

\- 📊 \*\*Amazon CloudWatch:\*\* Monitors infrastructure metrics.

\- 💻 \*\*Linux, PHP, HTML, CSS, JavaScript:\*\* Application technologies.

\- 🔧 \*\*Nginx:\*\* Web server configuration.



&#x20;✨ Key Features

\- 🏢 Three-tier cloud architecture

\- 🌐 Public and private subnet separation

\- ⚖️ Load balancing and automatic scaling

\- 🗄️ Managed relational database

\- 📦 Object storage for application assets

\- 📊 Infrastructure monitoring
